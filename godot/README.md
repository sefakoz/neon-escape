# NEON ESCAPE ∞ — Godot 4 vertical slice

Open **godot/project.godot** with Godot 4.2+ and press F6/F5. No third-party assets required.

## Controls
- Touch: press and drag anywhere to guide the hero toward your finger.
- Mouse: click and drag.
- Keyboard: arrow keys or WASD (Godot default ui_* input actions).
- Pause button at top right; menu and restart buttons are touch enabled.

## Gameplay
Survive 90 seconds, collect yellow crystals, pick up green joker for 7 seconds of invulnerability and enemy destruction. Three enemy movement types; 3 lives; local best score; optional synthesized placeholder sound.

## Known limitations / not release ready
- Procedural art and SFX are placeholders, not polished licensed production assets.
- No native haptics integration, localization, age profiles, accessibility audit or full device QA.
- This is a first playable vertical slice, not a finished iOS/Android app.
- Open the project in the Godot editor and run it to verify compilation and gameplay before publishing.
